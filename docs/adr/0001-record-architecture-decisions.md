# ADR-0001: Record architecture decisions

- Status: Accepted
- Date: 2026-10-14

## Context

The repository packages governance skills whose behaviour depends on a few structural and policy choices. Without a record, the reasons for those choices are lost.

## Decision

Record significant decisions as ADRs in `docs/adr`, following [template.md](template.md) and the rules in [GOVERNANCE.md](../../GOVERNANCE.md).

## Consequences

Decisions are traceable and revisable by supersession. There is a small writing overhead for each significant change.
