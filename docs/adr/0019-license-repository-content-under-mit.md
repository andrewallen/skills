# ADR-0019: License repository content under MIT

- Status: Accepted
- Date: 2026-10-22
- Supersedes: [ADR-0004](0004-licence-not-yet-chosen.md)

## Context

The repository is public, and the owner has confirmed that the original repository content may be licensed for reuse. A single, permissive licence keeps reuse terms straightforward across the skills and supporting documentation.

## Decision

License the repository's original content under the MIT License. Keep the full licence text in the root `LICENSE` file and link to it from the repository's human-facing documentation.

## Consequences

People may use, copy, modify, publish, distribute, sublicense and sell the licensed content, provided they include the copyright and permission notice. The licence includes a warranty disclaimer and does not require derivative works to use the same licence. The repository's package behaviour and versions are unchanged.
